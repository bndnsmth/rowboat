# Rowboat v0.2.0

## What's new

- **Workspace AI assistance:** optional Codex, Claude Code and OpenCode V2
  integration for SQL authoring, questions and query-plan investigation. AI is off
  by default; context sharing and trusted investigation require explicit opt-in.
- **Database objects in the sidebar:** expand Procedures, Functions, Triggers and
  PostgreSQL Sequences alongside Tables and Views. Groups load on demand; search
  includes loaded objects and routine signatures. Clicking a routine inspects its
  definition without executing it.
- **Explicit reconnect:** reconnect from the workspace header, Connection menu,
  command palette or operation-error panel. SQL and parameter drafts stay open;
  reconnect never replays SQL or changes saved profiles/keyring entries. Active
  transactions are guarded; unknown outcomes require acknowledgement and a durable
  recovery checkpoint before session replacement.

## Install

```sh
mise use -g github:bndnsmth/rowboat@0.2.0
rowboat
rowboatctl --help
```

Alternatively, download the archive for your OS/CPU and its SHA-256 sidecar,
verify it, extract it and run the included `install.sh`. Each archive includes the
GUI and independent CLI. See [distribution and installation](../DISTRIBUTION.md).

## Important limits

- Linux archives target glibc 2.35 or newer and still require desktop/graphics
  libraries. macOS bundles target macOS 13 or newer; CI runs on macOS 15.
- **macOS apps are ad-hoc signed, not Developer ID signed or notarized.**
  Gatekeeper may block downloaded bundles. This release does not claim a seamless
  macOS installation or instruct users to disable security protections.
- Reconnect establishes a new physical session: temporary objects, session
  settings and SQLite attachments do not transfer. Unknown-outcome replacement
  requires writable local recovery storage. There is no automatic SQL retry.
- AI requires a separately installed supported agent. Trusted investigation is
  opt-in, not a sandbox. Read [AI privacy and compatibility](../AI.md) first.
- Dedicated refresh/reconnect hotkeys are not included; both actions are available
  through the command palette.
